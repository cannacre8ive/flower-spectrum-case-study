# Product brief

## Job

Show Spencer Gray's ability to turn specialized domain information into a connected, understandable product. The case study must demonstrate strategy, creative judgment, technical architecture, exception handling and finished output.

## Audience

Adult portfolio readers: prospective collaborators, employers and design/product clients. Plain-language explanation is a comprehension goal, not youth-directed promotion.

## Core narrative

Premium cultivators need more expressive information than broad labels and potency alone. A reviewed laboratory panel can inform a consistent visual vocabulary. That vocabulary carries into profile and social-format specimens, partner-brand adaptations and a custom print menu.

## Scope

- Four public pages: story, interactive walkthrough, method, evidence.
- Three fixed fictional PDF reports parsed locally.
- Explicit review confirmation, total reconciliation and supported-mass coverage checks.
- Same reviewed record across all renderers.
- Three fictional identities, square/profile/story formats, and matching print menus.
- Local PNG, SVG ZIP, JSON and PDF exports.
- Existing deployed tools linked and illustrated with current screenshots.

No uploads of private evidence, cloud catalog, authentication, automatic social publishing, live commerce or partner distribution is implemented here. The original suite remains separately available.

## Success rubric

Source integrity 25%; consistent record reuse 25%; understandable explanation 20%; visual craft 20%; honest claims 10%. These are acceptance criteria, not a fabricated outcome score.

## Next research

Observe adults unfamiliar with terpenes explain the difference between a lab percentage and a model share. Compare visual interpretations with blinded sensory reports before making predictive claims. Test lab formats outside the fixed fixtures. Verify physical menu and label output. Validate partner-review and revision workflows before any publishing integration.
