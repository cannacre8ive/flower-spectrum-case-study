# Flower Spectrum: from evidence to expression

An editorial portfolio case study for Spencer Gray. Audience: hiring teams, collaborators and prospective design/product clients. The main job is to make one integrated system understandable and inspectable.

## Direction, before implementation

The fingerprint is the visual signature. The layout pairs an oversized botanical specimen with quiet, left-aligned typography, then follows the same batch through a report, an identity, a family of communication formats and a printed menu. No unrelated stock imagery or copied Behance art.

- Fern ink #183E33; leaf paper #E8EDDF; pale pollen #E4DFB6; white #FFFFFF; olive caption #536153; deep forest #17352C.
- Canonical ten profile colors retained from Flower Spectrum. Color always accompanied by text.
- Newsreader regular for display headlines; DM Sans for body, UI and data. Self-hosted under OFL.
- Hero: left thesis, right giant fingerprint; wide specimen stage below. Narrative alternates full-width fields and generously spaced two-column sections. Only actual process steps receive numbers.
- Intentional motion: user-triggered changes to the fingerprint, batch and output; no autoplay decorative animation.

            one batch / one shared identity

## Review against the brief

Rejected a repeat of PRESSWRK's compressed poster type and red/violet industrial palette. Rejected a generic dark cannabis landing page with neon accents. The new direction borrows Flower Spectrum's existing natural palette and serif character; the fingerprint, not a leaf symbol or potency number, dominates. Simple educational explanations address adult readers without using child-directed branding.

## Honest demonstration

The new walkthrough uses fixed fictional reports and partner identities. It reads an actual local PDF, requires human review and generates educational portfolio specimens. The original working suite remains separately linked. No invented adoption, revenue, sensory-validation or AI-model-training claims. Automated publishing and cross-device synchronization are roadmap items.
